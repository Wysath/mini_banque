Projet de mini banque

Ceci est un projet de mini banque avec du JS

Utilisation en console (fonctions disponibles)

Ouvrez la console du navigateur (F12) et utilisez les fonctions suivantes :

  • createClient(prenom, nom) — crée et retourne un nouvel objet client. Ex : const c = createClient('Jean','Dupont')
  • createBankAccount(clientId, solde = 0, type = 'courant') — crée un compte pour un client existant. Ex : const a = createBankAccount(c.id, 100, 'épargne')
  • deleteBankAccount(accountId) — supprime un compte si son solde est à 0. Ex : deleteBankAccount(a.id)
  • deposit(accountId, amount) — dépôt sur un compte (amount > 0). Ex : deposit(a.id, 50)
  • withdraw(accountId, amount) — retrait (amount > 0 et ≤ solde). Ex : withdraw(a.id, 25)
  • transfer(fromAccountId, toAccountId, amount) — transfert entre comptes (crée deux entrées en historique). Ex : transfer(a.id, comptesBancaires[0].id, 10)
  • getAccountBalance(accountId) — retourne le solde du compte. Ex : getAccountBalance(a.id)
  • getAccountHistory(accountId) — retourne l'historique des transactions du compte. Ex : getAccountHistory(a.id)
  • getTotalBalance(id) — si id est un client retourne la somme de tous ses comptes, si c'est un compte retourne le solde du compte. Ex : getTotalBalance(c.id) ou getTotalBalance(a.id)
  • getBankTotalBalance() — retourne la somme de tous les comptes de la banque.
  • clients et comptesBancaires — tableaux exposés pour inspection directe (console.log les affiche).

Notes

  • Les fonctions loggent des messages d'erreur avec console.log lorsque l'opération est invalide (compte non trouvé, montant invalide, etc.).
  • Les transactions sont stockées dans account.history avec : { id, type, amount, balanceAfter, timestamp }.
  • Rechargez la page pour revenir à l'état initial si besoin.
